# 不存在的房间：千岛兼容迁移 PRD

由现有 `app/page.tsx`、`docs/story-bible.md` 与 `docs/game-flow.md` 反向整理。

## 目标与范围

玩家从千岛小程序入口直接进入既有 ARG。保留开场、物业系统检索、1204 搜救、1304 调查、1104 私人日记、1404 身份调查、两种结局及完成后彩蛋。不改剧情、答案、门槛或演出节奏。沿用触屏点击替代拖拽、人工逐帧复核及摄像头离线校验。

首阶段采用 Taro Vue 3 + EMP 的原生单页 `web-view` 容器。游戏本体仍是本仓库的 Next/React 静态网页，不是原生组件重写，不支持完整离线游玩。网页必须另行托管 HTTPS；容器包不包含游戏媒体。若目标千岛宿主不支持 web-view 或业务域名，此路线不能发布，应重新评估原生迁移。

## 产品边界

- 游戏里的登录、工单与留言属于虚构单机剧情，不是真实登录、发帖或 IM。
- 无千岛身份信息读取，无服务端数据请求，无 AppSecret、数据库、积分或召回。
- 摄像头不是解谜必需能力：千岛模式不申请摄像头权限，使用既有无画面校验。
- 存档只在网页所属域名和宿主的本地存储中，不宣称浏览器/千岛/不同设备自动互通。

## 验收

1. 首次进入直接显示原有开场，无多余欢迎或授权屏。
2. 容器加载失败/超时可重试，不能清除存档；构建时 URL 必须为明确 HTTPS 地址，不接受入口 URL 参数换域。
3. 保持 `chengjiang-search-arg-v1` 存档结构；存储不可用时提示，不能白屏。删除失败不能假称已清除。
4. 切后台暂停音乐、录像和分轨；回来不自动重播案件音频，背景音乐在玩家操作后恢复。
5. 通过原网页回归、独立适配测试、Taro 编译与 EMP 本地打包。
6. 千岛 Android/iOS 真机完成 `docs/game-flow.md` 主线、结局和存档回归后才能认为可发布。
