# 不存在的房间 · 千岛容器设计

从既有 `app/globals.css` 的开场、登录与按钮样式提取。不是游戏页面重设计；原游戏继续在网页中按原样呈现。

- 方向：直接进入游戏，保留物业终端的克制感；不新增欢迎页、账号中心或 TabBar。
- 原生导航栏：由宿主提供，标题为「不存在的房间」，背景取开场 #050708。
- 连接状态：只在加载和实际失败时存在，不作为单独产品首页。
- 原有颜色：开场 #050708、文字 #ffffff、醒来页辅助文案 #b7c0bf、边框 #343f41、业务按钮 #275f7b。
- 字号：标题 20、正文 15、标签 12 逻辑像素；Taro 750 设计稿对应 40/30/24px。
- 公共类：`status-panel` 连接状态布局；`status-panel__label/title/copy/action` 对应标签、标题、说明、重试操作；`tap-active` 提供按压反馈。
- 只用纵向 Flexbox，不新增图标、营销卡片或动画。底部包含安全区。
- WebView 位于页面起点，状态层固定覆盖，不占据流式空间，避免将原生网页层推到屏幕下方。原生层叠仍需真机确认。
- 原生 token 仅放 `frontend/src/app.css` 的 `page`。网页 CSS 不属于原生编译输入，保留现状。
